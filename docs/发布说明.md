# 发布内容与 checkpoint 校验

本仓库保留 2026-09-25 旧阶段的代码、流程文档、脱敏训练指标、聚合评测结果和四个完整 checkpoint。2026-09-28 新增 20 万题阶段的代码、聚合评测记录及四个仅供推理的 checkpoint。裁剪后的 `Qwen3.5-2B-Text/model.safetensors` 不在仓库或 checkpoint 压缩包内。

## 20 万题推理检查点

新文件位于 `checkpoints/200k/`，分别对应第 7,500、9,000、10,000、12,500 步。每个 ZIP 只含 `adapter/adapter_config.json`、`adapter/adapter_model.safetensors`、`score_head.pt` 和 `checkpoint.json`。其中 `adapter_config.json` 的基座路径改为 `Qwen/Qwen3.5-2B`，权重与评分头的原始 SHA-256 记录于 `checkpoint.json`。本轮包不含 `training_state.pt`，不能从包内恢复优化器或训练调度器。

各 ZIP 的 SHA-256 见 `checkpoints/200k/SHA256SUMS.txt`，构建清单见 `checkpoints/200k/PACKAGE_MANIFEST.json`。原始完整 ZIP 的 SHA-256 也记录于各包的 `checkpoint.json`。使用时将 ZIP 解压到 `result/unpacked/mix200k-20260928/`，使子目录名为 `step-009000` 等。基座需使用 Qwen 原生多模态模型，训练与本机评测使用的上游提交为 `15852e8c16360a2fea060d615a32b45270f8a8fc`。评测入口及限制见[20 万题训练与评测记录](20万题训练与评测-2026-09-28.md)。

## 基座重建校验

- 原始基座：`Qwen/Qwen3.5-2B`，提交 `15852e8c16360a2fea060d615a32b45270f8a8fc`。
- 原始权重 SHA-256：`aa33250c4fc64891ddfaba3a314fd9542ea371843c387178b425fbcc5ed680b1`。
- 文本权重 SHA-256：`6c2df657da48151eafd02f33c1cc1f0dd1524043cb67b368fdac6d09e98f6851`。
- 转换输出：320 个张量，1,881,825,088 个参数，3,763,691,928 字节。

这些值来自本地 `models/Qwen3.5-2B-Text/conversion.json`。上游权重另行下载，使用 `jev/convert_text_model.py` 转换。若输出 SHA-256 不匹配，应核对上游修订、下载完整性和转换脚本版本。

## 仓库文件范围

仓库包含训练脚本、数据构建脚本、模型转换脚本、聚合训练曲线、固定测试集的构建与评测脚本、自拟题和聚合报告。公开训练日志经过筛选，保留启动阶段、训练步、验证与 checkpoint 事件。原始题库、生成后的训练集、200 道留出题正文、逐题预测、原始未筛选日志、本机虚拟环境与基座权重均不发布。

`origin/1.docx` 与 `origin/arch_image.png` 保留项目的最初讨论和架构图。图中的部分设计没有进入最终训练代码，差异见 `docs/起点文件说明.md`。两份文件按原始字节复制，DOCX 的作者元数据为 `Mo Xi`。

数据生成需访问各来源原始文件并遵守其许可。公开发布 checkpoint 不改变上游模型与数据来源的条件；使用者应自行核对相应条款。
