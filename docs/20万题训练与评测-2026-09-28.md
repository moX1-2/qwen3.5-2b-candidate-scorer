# 20 万题训练与评测记录，2026-09-28

## 实验设置

本轮从旧 8 万题阶段第 5,000 步权重热启，扩展语言 LoRA 至 `r=16、alpha=32`，冻结 Qwen3.5-2B 原生多模态基座及视觉编码器。训练样本共 200,000 道，包含旧阶段去重回放 79,958 道、RACE 73,919 道、HellaSwag 39,905 道和带图像的 ScienceQA 6,218 道。固定验证集为 2,500 道，其中原验证题 1,000 道，RACE、HellaSwag、ScienceQA 各 500 道。数据配方来自本轮运行配置和 `data/mix200k/manifest.json`；公开仓库提供 `datasets/prepare_200k.py`，不再分发生成后的训练题或图像。

训练使用峰值学习率 `1e-5`、16 题梯度累积、4,096 token 长度上限和一轮 12,500 步。运行配置记录 `text_prefix_sharing=True`；日志末段的前向模式为 `full_batch_dynamic`，不能据配置项推断每一步实际使用前缀共享。训练集和验证集 SHA-256 分别为 `28ab75a8e1cefd323b346fd9ff0e3f3e75c40b8c55ee2e0e8114008bffa3215c`、`6fe4b4fd73f10a14e47c3f8369bbfc2bac8f329f5d4bbe9645f37c6cd1e9c3b2`。

## 本机独立文本留出评测

四个检查点于 2026-09-28 在 RTX 4060 Laptop GPU 上使用 BF16 和完整前向评测。同一批 200 道留出题来自 ARC、BoolQ、C3、CommonsenseQA、OCNLI 的其他样本，每来源 40 道；另有 20 道较简单的自拟题。推理使用 `jev/common.py` 的候选提示和 `jev/shared_prefix_training.py` 的 `score_question(shared=False)`。测试文件的 SHA-256 为 `cbe727fde38ecd797ac081aa67d898177b6fd4cfbf0e14cc5f3f5efdd02c3995`、`f03595f3c484db25eb12c04d59368e1ef80d88bcab65182eaf9a712c802fe64b`。

| 检查点 | 留出题正确数 | 留出题 NLL | 留出题 Brier | 自拟题正确数 |
|---|---:|---:|---:|---:|
| 第 7,500 步 | 168 / 200 | 0.49157 | 0.24454 | 20 / 20 |
| **第 9,000 步** | **170 / 200** | **0.46821** | **0.23586** | 20 / 20 |
| 第 10,000 步 | 169 / 200 | 0.48092 | 0.23894 | 20 / 20 |
| 第 12,500 步 | 170 / 200 | 0.48630 | 0.23900 | 20 / 20 |

第 9,000 与第 12,500 步在 200 道留出题上的预测位置完全相同，后者 NLL 高 0.01810。旧阶段第 5,000 步在同一批题上答对 169 道、NLL 0.44178；新第 9,000 步多答对 1 道，NLL 较高。旧评测使用提取后的文本骨干及 1,024 token 上限，新评测使用原生多模态骨干及 4,096 token 上限。两次测试文件和候选提示函数相同，全部 220 题最长候选分支为 709 token，未触及旧长度上限。模型入口的差异仍需纳入解释。

这些留出题均为文本，且来自已有训练来源。当前没有独立图文留出集、跨来源测试或中文专项复测结果。200 题上的 1 题差值不能证明总体准确率提高。

## 公开权重与复评

`checkpoints/200k/` 提供第 7,500、9,000、10,000、12,500 步的推理 ZIP。每包含 adapter、评分头和来源摘要，不含 `training_state.pt`。四包的公开 SHA-256 见 `checkpoints/200k/SHA256SUMS.txt`；原始完整 ZIP 的 SHA-256 及权重文件 SHA-256 见包内 `checkpoint.json`。公开包可推理，不能直接恢复优化器和调度器。

以下命令使用原生多模态基座，采用本机评测的完整前向路径：

```bash
hf download Qwen/Qwen3.5-2B \
  --revision 15852e8c16360a2fea060d615a32b45270f8a8fc \
  --local-dir models/Qwen3.5-2B
bash jev/setup_env.sh
jev/.venv/bin/python -m pip install -r jev/requirements_200k.txt
mkdir -p result/unpacked/mix200k-20260928
unzip -q checkpoints/200k/jev-200k-step009000-inference.zip \
  -d result/unpacked/mix200k-20260928
jev/.venv/bin/python jev/predict_200k.py \
  --model models/Qwen3.5-2B \
  --checkpoint result/unpacked/mix200k-20260928/step-009000 \
  --question '18 加 27 等于多少？' \
  --candidate 44 --candidate 45 --candidate 46 \
  --language zh --full-forward
```

`scripts/evaluate_200k_arrivals.py` 可用 `--checkpoint`、`--model`、`--checkpoint-dir`、`--heldout`、`--custom` 指定复评输入。200 道留出题正文未随公开包分发；原仓库的 `result/evaluation-2026-09-25/make_test_sets.py` 保存抽样过程，重建数据时应核对来源版本和测试文件摘要。原始题库各有使用条件，旧回放部分含带非商业条款的数据源。
